# Práctica 2 - GesSec S.L.

Proyecto para la asignatura Interacción Persona-Computadora (IPC), Grado en Ingeniería Informática.

## Descripción
Aplicación de escritorio en Java Swing siguiendo la arquitectura Modelo-Vista-Controlador (MVC) para la gestión de incidencias de seguridad.

## Estructura
- `modelo/`: Lógica de negocio y gestión de datos.
- `vista/`: Interfaces gráficas (Swing) y formularios.
- `controlador/`: Gestión de eventos, navegación y lógica de flujo.
- `principal/`: Clase principal de ejecución (`Main`).

## Requisitos
- Java JDK 21.
- Apache NetBeans 28.
